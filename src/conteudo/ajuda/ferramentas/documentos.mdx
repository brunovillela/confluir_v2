Os **documentos** são o repositório de arquivos da entidade, organizados por
categoria.

## Organização por categoria

Cada documento pertence a uma categoria, o que mantém o acervo navegável. Você
sobe, consulta e organiza os arquivos por aqui.

<Aviso tipo="atencao" titulo="Arquivos legados no CDN anterior">
  Documentos migrados ainda apontam para o endereço de arquivos do sistema
  anterior. A re-hospedagem no armazenamento próprio é um passo pendente da
  virada.
</Aviso>
