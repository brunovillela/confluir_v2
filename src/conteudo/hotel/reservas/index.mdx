A reserva nasce de um **cupom**: o sindicato emite o cupom para o filiado, e o
hotel o transforma em uma **reserva** confirmada.

<Aviso tipo="nota" titulo="O cupom vem antes">
  Você não cria o cupom — ele é emitido pelo sindicato e aparece na lista
  **Cupons aguardando reserva**. O hotel apenas confirma a hospedagem.
</Aviso>

## Registrar uma reserva

<PassoAPasso>
  <Passo titulo="Abrir o formulário">
    No Início, clique em **Registrar reserva**.
  </Passo>
  <Passo titulo="Período e hóspedes">
    Informe check-in e check-out e marque os cupons dos hóspedes. Para quarto
    coletivo, marque a opção — ela vale para hóspedes que aceitaram dividir o
    quarto (mínimo de dois).
  </Passo>
  <Passo titulo="Conferir a tarifa e efetivar">
    O rodapé mostra a tarifa prevista para a quantidade de hóspedes. Clique em
    **Efetivar reserva** — os cupons ficam vinculados a ela com a tarifa.
  </Passo>
</PassoAPasso>

## Acompanhar a reserva

Abrindo uma reserva você vê os hóspedes e pode:

<PassoAPasso>
  <Passo titulo="Registrar o comparecimento">
    Marque **Compareceu** para cada hóspede que se hospedou — é isso que libera
    a reserva para faturamento.
  </Passo>
  <Passo titulo="Vincular ou desvincular cupom">
    Enquanto a reserva não é finalizada, dá para incluir outro cupom ou remover
    um hóspede.
  </Passo>
  <Passo titulo="Relatório e finalizar">
    Anexe o relatório da hospedagem quando for pedido e use **Finalizar** para
    encerrar (dá para reabrir se precisar).
  </Passo>
</PassoAPasso>

## Erros comuns

- **"Não aparece nenhum cupom para reservar."** Os cupons são emitidos pelo
  **sindicato**; se a lista **Cupons aguardando reserva** está vazia, ainda não
  há cupom para o seu hotel.
- **"A reserva não fica pronta para faturar."** Marque **Compareceu** para os
  hóspedes — é o comparecimento que libera a reserva para o faturamento.
- **"Marquei quarto coletivo, mas só tem um hóspede."** O quarto coletivo vale
  para **dois ou mais** hóspedes que aceitaram dividir; com um só, use quarto
  normal.
- **"Preciso corrigir uma reserva já finalizada."** **Reabra** a reserva para
  incluir/remover hóspede ou ajustar, e finalize de novo.
